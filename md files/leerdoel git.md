# Leerdoel GIT (deel 1) – SOSU GAME

## Leerdoel (SMART)

Ik wil tijdens Programming 101 (29 september t/m 9 oktober) na elk afgerond onderdeel van mijn game een commit maken met een korte, duidelijke Engelse message die zegt wat ik heb gedaan. Mijn doel is minimaal 10 commits verspreid over de sprint, zonder messages als "update" of "fix". Elke vrijdag kijk ik in mijn commitgeschiedenis of dat gelukt is.

- **Specifiek:** commit na elk afgerond onderdeel (menu, levelkeuze, pauze, resultaten, opties, game).
- **Meetbaar:** minimaal 10 commits met een message die zegt wat er gedaan is.
- **Acceptabel:** past bij hoe ik werk: ik bouw het spel scherm voor scherm.
- **Realistisch:** één commit per onderdeel is goed te doen.
- **Tijdgebonden:** tot de sprint review van vrijdag 9 oktober.

## Resultaat

- Ik heb meer dan 10 commits gemaakt, verspreid over 29 september t/m 5 oktober. Bijna elke commit hoort bij één onderdeel van het spel.
- Wat beter kan:
  - Er zitten typfouten in een paar messages ("ccontinue", "finsished", "addrd").
  - "Everything is ready." zegt niet wat er gedaan is.
  - "Cleaned and sorted my code also addrd some features." zijn eigenlijk twee dingen in één commit. Dat had ik beter in twee commits kunnen splitsen.
  - Ik heb een keer een merge gehad ("Merged changes") omdat ik lokaal werkte terwijl er online een wijziging stond. Volgende keer eerst `git pull` voordat ik begin.
